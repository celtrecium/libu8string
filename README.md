# libu8string
A small UTF-8 library for solving common cases in C

## build and install
### build as a static library 
```
make static
```
### build as a shared library
```
make shared
```
### build both versions
```
make
```
### install
```
sudo make install
```
### uninstall
```
sudo make uninstall
```
